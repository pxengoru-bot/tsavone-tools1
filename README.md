# tsavone-tools1

Tools for Tsavone Consulting.

| Folder | What it is | Guide |
|---|---|---|
| [`training/`](training/) | Training website: live course finder from the Google Sheet, fee estimator and booking form | [training/README.md](training/README.md) |
| [`register/`](register/) | Google Apps Script for the Tsavone Training Register: results, certificate IDs, PDF certificates with QR codes, Gmail drafts, course summaries and a public verification page | [register/INSTALL.md](register/INSTALL.md) |
| [`tenders/`](tenders/) | Google Apps Script for the private Tsavone Tender Tracker: tender log with deadline colours, bid folders and checklists matched to company documents, dashboard and a daily reminder email | [tenders/INSTALL.md](tenders/INSTALL.md) |
